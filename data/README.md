# Data

The production repository does not bundle the source CSV.

The prototype uses the Government of Canada dataset:

**Greenhouse Gas Emissions Inventory — Energy Use Related to
Individual Federal Facilities**

Source:

https://open.canada.ca/data/en/dataset/6bed41cd-9816-4912-a2b8-b0b224909396

Current prototype scope:

- Fiscal year: FY2024-25
- Atlantic Canada
- Nova Scotia
- New Brunswick
- Newfoundland and Labrador
- Prince Edward Island
- 535 loaded facility records

The PostgreSQL application account is read-only.
